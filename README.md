   # JPEG Quality Factor Trade-off on the Kodak Suite
   Code and results for: "Trade-off Analysis of JPEG Quality Factor for Image Compression Efficiency and Structural Quality" (CEPAT).

   ## Run
   Open `jpeg_qf_tradeoff.ipynb` in Google Colab and choose Runtime → Run all.
   The notebook downloads the 24 Kodak images itself; they are not redistributed here.

   ## Contents
   - `jpeg_qf_tradeoff.ipynb`: experiment (JPEG, WebP, AVIF; PSNR, SSIM, MS-SSIM; statistics)
   - `requirements.txt`: library versions used
